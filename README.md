# 镇主传说 · Town Legend

一款运行在浏览器中的 2D 像素风卡牌放置游戏。玩家扮演城镇领主，通过购买并部署卡牌来管理经济链（战斗 → 制造 → 商店），同时应对不断涌现的怪物威胁，推动城镇持续升级。定位为"放置观赏型"：人物自行活动，玩家只需做关键决策。

## 技术架构

| 层 | 技术 |
|---|---|
| 游戏引擎 | Phaser 3（WebGL / Canvas，像素渲染，antialias 关闭）|
| 语言 | TypeScript |
| 构建工具 | Vite |
| 状态管理 | 自研响应式 `GameStore`（发布/订阅模式）；城镇升级时发出 `townLevelUp` 事件，`TownScene` 监听并调用 `rebuildWorldVisuals()` 实时重绘世界视觉 |
| UI 层 | 原生 DOM（卡牌面板、HUD、弹窗覆盖在 canvas 之上）|
| 像素图形 | 纯代码绘制：`Phaser.GameObjects.Graphics` → `generateTexture` |
| 存档 | `localStorage`（JSON 序列化，版本号 `6`）|

源码结构：

```
src/
├── main.ts
├── types.ts
├── config/
│   └── zones.ts          # 区域坐标单一来源：ZoneConfig 接口 + computeZoneConfig()，替代原散落的三处硬编码
├── data/
│   ├── cards.ts          # 卡牌定义 + 升级映射 + 彩蛋映射 + 商店规模/刷新费
│   └── items.ts          # 战利品 / 成品 / 配方定义
├── systems/
│   └── store.ts          # 游戏状态机（含彩蛋合成、攻城判断、出售、升级逻辑、成就系统）
├── scenes/
│   └── TownScene.ts      # 场景：巢穴系统、怪物AI、战士回血、伤害飘字、年度总结弹窗、成就解锁弹窗、拖拽放卡区域高亮
└── ui/
    └── UIController.ts   # 出售按钮、商店刷新价格动态显示、成就面板、手牌拖拽放卡状态机
```

## 时间系统

时间**完全自动推进**，玩家无法暂停。

| 单位 | tick 数 | 实际时长 |
|---|---|---|
| 1 tick | 1 | **200 ms** |
| 1 周 | 40 tick | **8 秒** |
| 1 月 | 160 tick（4 周）| **32 秒** |

> tick 从 125ms 调整为 200ms，目的是让战斗过程（攻击间隔、移动）有足够时间被玩家观察。

## 卡牌系统

### 商店规模

商店展示卡牌数量随城镇等级动态扩展：

| 城镇等级 | 商店卡牌数 |
|---|---|
| 1 | 5 |
| 2 | 7 |
| N | 3 + N×2 |

- **1级城镇**只能看到 0 级人物卡和怪物卡，**建筑卡和魔法卡最低 2 级**，需升至 3 级后才会出现。
- 所有格全部售出后**自动刷新**。
- 手动刷新费用 = `LEVEL_COST[townLevel - 1]`（当前等级减1对应的卡牌售价），随城镇等级增加，防止频繁刷新加速升级节奏。

### 定价规则

| 卡牌等级 | 购买价 | 场上维护费/月 |
|---|---|---|
| 0 | 20 | 5 |
| 1 | 50 | 10 |
| 2 | 100 | 20 |
| 3 | 180 | 35 |
| 4 | 300 | 55 |
| 5 | 480 | 80 |

> **手牌不收维护费。怪物卡维护费永远为 0。场上不活跃（罢工/休息中）的卡牌当月不收维护费。**

### 出售卡牌

任意手牌或场上卡牌可以出售，回收购买价的 **30%**（最低 1 金币）。

- **例外**：场上怪物卡出售时**回收金额为 0**（不返还金币）；手牌中的怪物卡仍按 30% 回收。

### 打出卡牌

- **人物卡**：打出后弹出岗位选择窗口（商店 / 制造 / 战斗）。
- **怪物卡**：直接上场，**自动分配出生点**（按上场顺序，无需玩家选择）。
- **建筑卡**：直接上场，按卡牌类型自动排列在对应功能区附近（小摊位→商店区，工坊→制造区，旅馆→大厅，兵营→兵营区），多张同类横向错开 ±70px，静态显示不动画。
- **魔法卡**：直接上场，**不在场上显示精灵**，效果以 Chip 形式显示在顶栏下方的 Buff 栏。
- 场上的牌可以出售，但不能收回手牌。

### 升级（3张合1张）+ 彩蛋机制

集齐手牌 + 场上**共 3 张相同 id 的卡牌**可触发升级：

- 销毁 3 张原卡
- 生成 1 张**下一级同类型新卡**加入手牌（固定映射，见数据总表）
- 没有升级目标的卡牌（最高级）无法合成
- 每次合成有 **2% 概率触发彩蛋**，生成同等级的特殊稀有卡而非普通升级目标
- 彩蛋卡全属性碾压同等级普通卡，但**不可再升级**，也不在商店出售

所有区域坐标均由 `src/config/zones.ts` 的 `computeZoneConfig(townLevel)` 统一计算（单一来源），不再硬编码。

### 快速放卡（拖拽手势）

除点击菜单外，手牌支持**拖拽直放**：将卡片拖到游戏画面高亮区域即可完成打出，无需弹窗确认。

| 卡牌类型 | 拖放目标 | 效果 |
|----------|----------|------|
| 人物卡 | 商店 / 制造 / 大厅 / 兵营 高亮区 | 自动分配对应岗位，跳过岗位选择弹窗 |
| 怪物卡 | 左侧或右侧城墙外高亮区 | 自动分配出生点 |
| 建筑卡 | 城墙内任意高亮区 | 直接上场 |
| 魔法卡 | 城墙内任意高亮区 | 立即打出 |

**行为细节**：
- 拖拽距离 < 8 px 时判定为**点击**，仍走原有点击菜单流程（兼容触控短按）
- 拖放到无效区域时静默取消，卡牌留在手牌
- 场上满员时显示提示"场上已满！"，放卡失败
- 拖拽过程中摄像机平移被暂停

**原点击流程完整保留，两种方式可自由选择。**

## 场上角色行为

### 人物

| 岗位 | 区域 | 行为 |
|---|---|---|
| 商店 | x = 1100 ± 40 | 随机漫步，行人经过时走向行人服务 |
| 制造 | x = 1400 ± 40 | 随机漫步，头顶显示琥珀色进度条 |
| 战斗 | 见战士状态机 | 巡逻 / 追击 / 战斗 / 捡取战利品 / 回兵营回血 |
| 无（Idle）| x = 1800 ± 40 | 城镇大厅随机漫步 |

不活跃（受伤 / 罢工）的人物：透明度降低，飘向城镇大厅。

**精灵动画（interpolate）：**
- 移动时：sin 函数 ×4 步伐弹跳（bobPhase 驱动）。
- 静止时：制造工人呈轻微锤击前倾角，商店工人服务前倾角，怪物呼吸缩放。
- 战士追击/战斗时：轻微旋转（追击偏向目标方向，战斗中随机左右摆动）。
- 受击（hitFlash）期间：角度摆动由专属 tween 控制，不被 interpolate 覆盖。

### 怪物

| 状态 | 行为 |
|---|---|
| waiting（aggressionCountdown > 0，或倒计时=0但有活跃战斗岗位人员）| 在巢穴附近徘徊，战士仍会主动追击 |
| marching（aggressionCountdown = 0 且无活跃战斗岗位人员）| 向城镇大厅行进 |
| attacking | 进入城墙范围，攻击最近的活跃人物 |
| retreating | 城内所有人物已倒下，返回巢穴重置 |
| injured（hp ≤ 0）| 放大后缩小消失动画（约0.6秒），3个月后在巢穴刷出满血 |

### 移动速度

| 角色类型 | 速度 |
|---|---|
| 人物 | 20 px / tick（约 100 px/s）|
| 怪物 | 14 px / tick（约 70 px/s）|
| 战士（回血中）| 14 px / tick |

## 战士状态机

战斗岗位人物拥有六状态 AI，优先级从高到低：

```
1. heal     → 无怪物且血量未满，走向兵营回血
2. loot     → 正在前往战利品掉落点捡取
3. return   → 捡取完毕，返回兵营
4. fight    → 距离怪物 < 60px，停下攻击
5. chase    → 发现怪物（随时主动出击），追击最近的一只
6. patrol   → 无怪物无战利品且满血，来回巡逻
```

**回血流程：**
1. 无活跃怪物且战士 HP < 最大值时，切换到 `heal` 状态。
2. 走向兵营（x=2200），到达后每 tick 回复 `maxHp/40` 点血量。
3. 偶尔在头顶弹出 ❤️ 气泡，血量满时弹出 💪 气泡并切回 `patrol`。
4. 期间若有新怪物出现，立即切回战斗优先级。
5. 回血时精灵显示绿色光晕（tint 0xaaffaa）。

| 参数 | 数值 | 说明 |
|---|---|---|
| 攻击距离 | 60 px | 战士停在怪物60px外攻击，不再重叠 |

## 战斗系统

### 侵略倒计时

怪物上场后初始化 `aggressionCountdown = aggression`（月数）。若场上有**恐惧术**魔法卡，上场时额外加上 `delay_aggression` 的加成值。每月末减 1，归零时**若场上无活跃战斗岗位人员**（`hasActiveCombatWorkers = false`）则开始向城镇进军；若归零时仍有战斗岗位人员则继续等待。**战士在任何时候都会主动追击活跃怪物**，无论倒计时是否归零。

### 实时战斗（tick 级别）

战士追至距离 < 60px 时停下进入攻击循环（不再相互重叠）：

- `attackCooldown` 每 tick 减 1，归零时触发攻击，重置为 **8**。
- 命中时生成**伤害飘字**（红色 `-N` 向上飘动消失）。
- 命中时双方精灵短暂变色（怪物闪 `0xff3333`，人物闪 `0xff9966`）。
- 命中时生成粒子特效（8个彩色方块四散）。
- 命中时双方精灵播放**角度摆动 tween**（±10–12°，yoyo 回弹）；怪物攻击人物时人物同样触发角度摆动。

伤害计算（含全部魔法/建筑加成）：

```
finalAtk    = (human.atk + buff_human_atk + barracksBonus + allBuff) × combatFuryMult
finalDef    = (human.def + buff_human_def + barracksDefBonus + allBuff) × divineDefMult
monFinalAtk = monster.atk - debuff_monster_atk - greatDebuff

dmgToMonster = max(1, round(finalAtk) - monster.def)
dmgToHuman   = max(0, monFinalAtk - round(finalDef))
```

其中：
- `combatFuryMult`：战争号角效果（`combat_fury` power=50 → ×1.5）
- `divineDefMult`：神圣护佑效果（`divine_def` power>0 → ×2）
- `greatDebuff`：永恒诅咒效果（`great_debuff` power=15）
- `allBuff`：全能祝福效果（`all_buff` power=10）

### 战斗结果

**怪物 HP ≤ 0**：
- 精灵播放放大→缩小消失动画（约 0.6 秒），期间 `isDead=true` 阻止 sprite 重建
- 在怪物位置生成战利品包
- 怪物实体标记 `isActive=false`，`restMonthsLeft=3`
- 巢穴显示脉冲光圈休息动画
- 3 个月后月末恢复：巢穴动画消失，满血怪物刷出，`aggressionCountdown` 重置

**人物 HP ≤ 0**：HP 重置，`isActive=false`，`restMonthsLeft=townLevel`，精灵半透明飘向城镇大厅。

### 怪物攻城行为

- 怪物进入城墙范围（`x` 在 900~2700 之间）后切换为 `attacking` 状态。
- 攻击城内最近的**任意活跃人物**（不分岗位）。
- 若城内**所有人物都处于 `isActive=false`**：怪物切换为 `retreating`，走回巢穴，月末自动重置倒计时。

**`isUnderSiege`（真正攻城）判断条件（两者同时满足）：**
1. 场上存在 `aggressionCountdown=0` 且 `isActive=true` 的怪物
2. 场上**没有**任何 `jobAssignment=Combat` 且 `isActive=true` 的人物（`hasActiveCombatWorkers=false`）

> 若有战斗岗位人员在场，怪物即使倒计时归零也只是与战士交战，不触发攻城经济惩罚；战斗人员全部倒下/罢工后，`isUnderSiege` 才变为 `true`，经济惩罚随即生效。

### 攻城经济惩罚

- 攻城期间无法进行制造和商店营业。
- 怪物攻城**持续超过 1 个月**：下月月末税收为 0，日志警告。
- 月末会提示当月攻城时长，给玩家压力感。

       ↓
战士走去捡取 → 带回城镇 → 加入库存（战利品）

### 月末商店结算

```
innBonus       = 旅馆(+3) + 大旅馆(+8) + 宫殿(+15) + 神圣宫殿(+30)  // 各建筑capacity字段之和
magicExtra     = getMagicBonus('extra_passersby')                    // 市集魔法 +5
passersby      = 5 + townLevel×3 + magicExtra + innBonus
                 × 2（若黄金时代魔法激活）
sellCapacity   = min(totalProducts, passersby × 2)
shopPower      = sum(shopWorker.intellect)
stallMult      = 1 + sum((bonus-1) of 小摊位/大市集/贸易中心/世界市场)
craftPriceMult = 1 + getMagicBonus('craft_price_bonus') / 100        // 大师工艺 ×1.5
income per item = product.sellPrice × (1 + shopPower×0.05) × stallMult × craftPriceMult
```

### 制造速率加成叠加

```
buildingBonus = getCraftSpeedBonus()
              = 1 + (工坊×0.4) + (大锻造炉×1.5) + (炼金工坊×3.0) + (神圣锻造台×7.0)
hasteBonus    = 1 + getMagicBonus('craft_haste') / 100   // 时间加速 ×1.5
totalCraftMult = buildingBonus × hasteBonus
```

## 月末结算流程

每月 160 tick 结束时，按以下顺序执行（执行完毕后自动存档）：

1. **税收**：`baseTax × (1 + tax_bonus/100) × palaceMult`；攻城超过 1 月则为 0
   - `tax_bonus`：繁荣咒效果（+50%）
   - `palaceMult`：神圣宫殿效果（×2）
2. **攻城计时**：记录 `siegeMonthsCount`，连续攻城则下月税收为 0
3. **怪物侵略倒计时**：每只活跃怪物 `aggressionCountdown -= 1`
4. **商店收入**（攻城期间跳过）
5. **维护费**：场上非怪物且 `isActive=true` 的卡牌全额扣除；手牌和不活跃卡牌不扣；金币不足时从场上倒序标记罢工；罢工后调用 `checkSiegeTransition()` 更新攻城状态
6. **恢复**：休息 / 罢工计时器各减 1；归零时人物满血恢复，怪物满血重置倒计时
7. **城镇升级检查**
8. **累积年度统计**（每月将税收+商店收入/维护费累加入 `yearStats`）
9. **年终结算**（仅当 `month % 12 === 0` 时）：生成 `YearSummary`，触发 `yearSummary` 事件弹出年度总结弹窗，清零 `yearStats`
10. **成就检查**：调用 `checkAchievements()`，检查所有未解锁成就的触发条件
11. **重置月度统计计数器**

## 城镇升级

升级进度计算（Lv0 卡不计入升级进度）：

| 卡牌等级 | 贡献单位（以Lv1为基准） |
|---|---|
| Lv0 | **0**（不计入）|
| Lv1 | 1 |
| Lv2 | 3（= 3张Lv1）|
| Lv3 | 9（= 3张Lv2）|
| Lv4 | 27 |
| Lv5 | 81 |

升级阈值 = `10 × 3^(城镇等级-1)`（以Lv1单位计）

- 1→2级：需要 10 单位（等价 10 张Lv1卡，或 1张Lv2+7张Lv1，或 1张Lv3+1张Lv1，…）
- 2→3级：需要 30 单位（对标 10 张Lv2卡）
- 3→4级：需要 90 单位（对标 10 张Lv3卡）
- 4→5级：需要 270 单位（对标 10 张Lv4卡）
- 5→6级：需要 810 单位（对标 10 张Lv5卡）
- HUD 的"升级"格显示 `当前进度/目标`

> **注意：纯靠囤积Lv0卡无法升级城镇**，至少需要Lv1及以上卡牌。

### 预期游玩时长节奏

| 城镇等级 | 目标游玩时长 | 核心体验 |
|---|---|---|
| 1→2 | 约5分钟 | 教程期，摸清基础机制 |

升级效果：
- `townLevel += 1`

## 轮回系统

**触发条件**：城镇达到最高等级（6级）后，顶栏"♻ 轮回"按钮解锁可点击。

**轮回效果**：
- **清零**：金币重置为 120、城镇等级重置为 1、所有卡牌/场上/手牌/库存/日志清空、时间回到 Y1·M1·W1。
- **保留**：`achievements`（所有成就解锁状态永久保留）以及全部成就追踪计数器（`totalCardsBought`、`totalMonstersDefeated` 等），`reincarnationCount`（轮回次数累计）。

**操作流程**：
1. 点击顶栏"♻ 轮回"按钮 → 弹出确认弹窗（"轮回将清空所有卡牌、金币、时间进度，仅保留成就与轮回次数，确认吗？"）
2. 点击"✅ 确认轮回" → 调用 `store.reincarnate()`，商店自动刷新，日志记录"第 N 次轮回！"
3. 完成至少1次轮回后，顶栏额外显示"轮回 ♻ N"统计格（轮回次数归零时隐藏）。

### 高优先级

#### 行人系统视觉-经济联动重构（核心修复）
> 现状：视觉行人（街上行走的小人）与月末经济结算的"行人数"完全独立，视觉层的 💰 气泡不产生任何实际收入，导致玩家对行人系统无感。

- **打通视觉与收入**：行人进入商店区并触发交易时，产生一次即时小额收入（金币飘字 +N）；月末汇总改为对整月积累的统计说明，而非重新独立计算
- **行人停留行为**：行人到达商店区且库存有商品时，短暂驻足 1~2 秒（简短的缓停 tween）再离开；无商品或无工人时直接穿行，冷热对比一目了然
- **视觉行人密度与经济数值挂钩**：视觉行人的生成频率和屏幕上限跟随月度行人数动态缩放（旅馆多 → 街道更热闹），让建筑投资效果直接可见

### 中优先级

#### 商品售罄视觉提示
- 当月库存卖空后，行人经过商店区时显示"❌"气泡或简短摇头离开动画
- 让玩家直观感知"该补货了"，引导生产决策

#### 商店月度访客计数器
- 商店区域显示一块小牌，实时显示「本月已接待 N 人 / 上限 M 人」
- 帮助玩家在游戏中直接看到旅馆/宫殿的行人加成效果，不必翻日志

#### 彩蛋卡视觉区分
- 彩蛋卡在手牌/场上面板显示特殊金色边框和星形标记
- 合成触发彩蛋时播放全屏金光特效（约1.5秒）

#### 战士巡逻优化
- 随机短暂驻足（停 1-2 秒环顾四周）
- 多名战士错开巡逻相位

#### 事件系统（随机月度事件）
- 丰收之月：税收 +50%
- 商旅到来：本月行人 ×2（与行人系统联动，街道同步出现更多行人）
- 怪物增援：随机一只场上怪物 `aggressionCountdown -= 1`
- 神秘旅者：手牌随机获得一张免费卡
- 彩蛋事件（5%概率）：直接触发一次彩蛋合成

### 低优先级

#### 数值平衡调整
- Lv4/Lv5卡牌和建筑的数值需要真实游玩后调整
