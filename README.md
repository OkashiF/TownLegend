# 镇主传说 · Town Legend

一款运行在浏览器中的 2D 像素风卡牌放置游戏。玩家扮演城镇领主，通过购买并部署卡牌来管理经济链（战斗 → 制造 → 商店），同时应对不断涌现的怪物威胁，推动城镇持续升级。定位为"放置观赏型"：人物自行活动，玩家只需做关键决策。

## 技术架构

| 层 | 技术 |
|---|---|
| 游戏引擎 | Phaser 3（WebGL / Canvas，像素渲染，antialias 关闭）|
| 语言 | TypeScript |
| 构建工具 | Vite |
| 状态管理 | 自研响应式 `GameStore`（发布/订阅模式）|
| UI 层 | 原生 DOM（卡牌面板、HUD、弹窗覆盖在 canvas 之上）|
| 像素图形 | 纯代码绘制：`Phaser.GameObjects.Graphics` → `generateTexture` |
| 存档 | `localStorage`（JSON 序列化，版本号 `3`）|

源码结构：

```

├── main.ts

├── data/
```

## 时间系统

时间**完全自动推进**，玩家无法暂停。

| 单位 | tick 数 | 实际时长 |
|---|---|---|
| 1 tick | 1 | **200 ms** |
| 1 周 | 40 tick | **8 秒** |
| 1 月 | 160 tick（4 周）| **32 秒** |

> tick 从 125ms 调整为 200ms，目的是让战斗过程（攻击间隔、移动）有足够时间被玩家观察。

## 卡牌系统

### 商店规模

商店展示卡牌数量随城镇等级动态扩展：

| 城镇等级 | 商店卡牌数 |
|---|---|
| 1 | 5 |
| 2 | 7 |
| 3 | 9 |
| N | 3 + N×2 |

- **1级城镇**只能看到 0 级人物卡和怪物卡，**建筑卡和魔法卡最低 1 级**，需升至 2 级后才会出现。
- 6 张全部售出后**自动刷新**。
- 手动刷新费用 = `LEVEL_COST[townLevel - 1]`（当前等级减1对应的卡牌售价），随城镇等级增加，防止频繁刷新加速升级节奏。

### 定价规则

| 卡牌等级 | 购买价 | 场上维护费/月 | 手牌维护费/月（×0.5）|
|---|---|---|---|
| 0 | 20 | 5 | 3 |
| 1 | 50 | 10 | 5 |
| 2 | 100 | 20 | 10 |
| 3 | 180 | 35 | 18 |

> **怪物卡例外**：维护费永远为 0。

### 出售卡牌

任意手牌或场上卡牌可以出售，回收购买价的 **10%**（最低 1 金币）。

- **限制**：场上怪物卡正在攻城（`aggressionCountdown=0` 且 `isActive`）期间，该怪物卡**不可出售**，须等战斗结束。

### 打出卡牌

- **人物卡**：打出后弹出岗位选择窗口（商店 / 制造 / 战斗）。
- **怪物卡**：直接上场，**自动分配出生点**（按上场顺序，无需玩家选择）。
- **建筑卡、魔法卡**：直接上场，自动生效。
- 场上的牌可以出售，但不能收回手牌。

### 升级（3张合1张）

集齐手牌 + 场上**共 3 张相同 id 的卡牌**可触发升级：

- 销毁 3 张原卡
- 生成 1 张**下一级同类型新卡**加入手牌（固定映射，见数据总表）
- 没有升级目标的卡牌（最高级）无法合成

**升级映射：**

| 原卡 | 合成目标 |
|---|---|
| 农夫 Lv0 ×3 | 铁匠 Lv1 |
| 小贩 Lv0 ×3 | 商人 Lv1 |
| 守卫 Lv0 ×3 | 骑士 Lv1 |
| 商人 / 铁匠 / 骑士 Lv1 ×3 | 法师 Lv2 |
| 老鼠 Lv0 ×3 | 野狼 Lv0（同级，掉落更好）→ 实际升目标是野狼 |
| 野狼 Lv0 ×3 | 巨魔 Lv1 |
| 巨魔 / 鸟妖 Lv1 ×3 | 幼龙 Lv2 |

## 战士状态机

战斗岗位人物拥有六状态 AI，优先级从高到低：

```
1. heal     → 无怪物且血量未满，走向兵营回血
2. loot     → 正在前往战利品掉落点捡取
3. return   → 捡取完毕，返回兵营
4. fight    → 距离怪物 < 60px，停下攻击
5. chase    → 发现怪物（随时主动出击），追击最近的一只
6. patrol   → 无怪物无战利品且满血，来回巡逻
```

**回血流程（新增）：**
1. 无活跃怪物且战士 HP < 最大值时，切换到 `heal` 状态。
2. 走向兵营（x=2200），到达后每 tick 回复 `maxHp/40` 点血量。
3. 偶尔在头顶弹出 ❤️ 气泡，血量满时弹出 💪 气泡并切回 `patrol`。
4. 期间若有新怪物出现，立即切回战斗优先级。
5. 回血时精灵显示绿色光晕（tint 0xaaffaa）。

**攻击参数（调整后）：**

| 参数 | 数值 | 说明 |
|---|---|---|
| 攻击距离 | 60 px | 战士停在怪物60px外攻击，不再重叠 |
| 攻击 CD | 8 tick | 约 1.6 秒/次，战斗过程约 5-8 秒可观察 |
| 感知范围 | 800 px | 战士发现怪物的最大距离 |

## 战斗系统

### 侵略倒计时

怪物上场后初始化 `aggressionCountdown = aggression`（月数）。每月末减 1，归零时开始向城镇进军。**战士在任何时候都会主动追击活跃怪物**，无论倒计时是否归零。

### 实时战斗（tick 级别）

战士追至距离 < 60px 时停下进入攻击循环（不再相互重叠）：

- `attackCooldown` 每 tick 减 1，归零时触发攻击，重置为 **8**。
- 命中时生成**伤害飘字**（红色 `-N` 向上飘动消失）。
- 命中时双方精灵短暂变色（怪物闪 `0xff3333`，人物闪 `0xff9966`）。
- 命中时生成粒子特效（6个方块四散）。

伤害计算：

```
dmgToMonster = max(1, (human.atk + buff_human_atk + barracksBonus) - monster.def)
dmgToHuman   = max(0, (monster.atk - debuff_monster_atk) - (human.def + buff_human_def))
```

### 战斗结果

**怪物 HP ≤ 0**：
- 精灵在约 4 秒内渐渐透明消失（Phaser tween，不立即删除）
- 在怪物位置生成战利品包
- 怪物实体标记 `isActive=false`，`restMonthsLeft=3`
- 巢穴显示脉冲光圈休息动画
- 3 个月后月末恢复：巢穴动画消失，满血怪物刷出，`aggressionCountdown` 重置

**人物 HP ≤ 0**：HP 重置，`isActive=false`，`restMonthsLeft=townLevel`，精灵半透明飘向城镇大厅。

### 怪物攻城行为

- 怪物进入城墙范围（`x` 在 900~2700 之间）后切换为 `attacking` 状态。
- 攻击城内最近的**任意活跃人物**（不分岗位）。
- 若城内**所有人物都处于 `isActive=false`**：怪物切换为 `retreating`，走回巢穴，月末自动重置倒计时（相当于主动撤退且重新计时）。

### 攻城经济惩罚

- 攻城期间无法进行制造和商店营业。
- 怪物攻城**持续超过 1 个月**：下月月末税收为 0，日志警告。
- 月末会提示当月攻城时长，给玩家压力感。

## 经济链

```
战士击败怪物 → 战利品包掉落
       ↓
战士走去捡取 → 带回城镇 → 加入库存（战利品）
       ↓
制造人员积累勤劳点（头顶进度条）→ 满足配方自动合成 → 成品加入库存
       ↓
行人经过商店区 → 商店工人走向行人 → 月末批量结算售出收入
```

攻城期间：制造暂停，商店无收入，若持续超过1月则税收也归零。

### 配方

| 输入战利品 | 数量 | 输出成品 | 工时 |
|---|---|---|---|
| 🐭 鼠皮 | 3 | 🧤 皮革 | 8 |
| 🦷 狼牙 | 2 | ⚔️ 武器 | 12 |
| 💎 魔晶 | 1 | 🔮 魔法石 | 10 |
| 🪶 妖羽 | 4 | 🧣 羽毛斗篷 | 14 |
| 🐉 龙鳞 | 2 | 🛡️ 龙甲 | 20 |

### 月末商店结算

```
innBonus    = sum(capacity of active 旅馆 buildings)
passersby   = 5 + townLevel × 3 + getMagicBonus('extra_passersby') + innBonus
sellCapacity = min(totalProducts, passersby × 2)
shopPower = sum(shopWorker.intellect)
stallMult = 1 + sum((bonus - 1) of active 小摊位 buildings)   // 1 stall → 1.3; 2 stalls → 1.6
income per item = product.sellPrice × (1 + shopPower × 0.05) × stallMult
```

## 月末结算流程

每月 160 tick 结束时，按以下顺序执行（执行完毕后自动存档）：

1. **税收**：正常 `monthlyTax(townLevel)`；攻城超过 1 月则为 0
2. **攻城计时**：记录 `siegeMonthsCount`，连续攻城则下月税收为 0
3. **怪物侵略倒计时**：每只活跃怪物 `aggressionCountdown -= 1`
4. **商店收入**（攻城期间跳过）
5. **维护费**：场上非怪物牌全额扣除，手牌 ×0.5；金币不足时从场上倒序标记罢工
6. **恢复**：休息 / 罢工计时器各减 1；归零时人物满血恢复，怪物满血重置倒计时
7. **城镇升级检查**

## 城镇升级

升级条件：`手牌 + 场上卡牌总数 >= 10`（持有任意等级卡牌均计入）

升级效果：
- `townLevel += 1`
- 场上牌槽上限：`5 + (townLevel - 1) × 2`
- 商店自动刷新，商店规模扩展（+2格）
- 1→2级时商店开始出现建筑卡、魔法卡、Lv1卡

## 存档系统

- 存档时机：每月末结算完成后自动写入 `localStorage`，key 为 `town_legend_save`。
- 版本号：`3`（与旧版不兼容，升级后会忽略旧存档）。
