# 镇主传说 · Town Legend

一款运行在浏览器中的 2D 像素风卡牌放置游戏。玩家扮演城镇领主，通过购买并部署卡牌来管理经济链（战斗 → 制造 → 商店），同时应对不断涌现的怪物威胁，推动城镇持续升级。

## 技术架构

| 层 | 技术 |
|---|---|
| 游戏引擎 | Phaser 3（WebGL / Canvas，像素渲染，antialias 关闭）|
| 语言 | TypeScript |
| 构建工具 | Vite |
| 状态管理 | 自研响应式 `GameStore`（发布/订阅模式）|
| UI 层 | 原生 DOM（卡牌面板、HUD、弹窗覆盖在 canvas 之上）|
| 像素图形 | 纯代码绘制：`Phaser.GameObjects.Graphics` → `generateTexture` |
| 存档 | `localStorage`（JSON 序列化，版本号 `2`）|

源码结构：

```
src/
├── main.ts                  # Phaser 初始化 + 世界尺寸常量 + 布局同步
├── types.ts                 # 全局类型定义
├── data/
│   ├── cards.ts             # 所有卡牌静态定义 + 抽卡逻辑
│   └── items.ts             # 战利品 / 成品 / 配方定义
├── systems/
│   └── store.ts             # 游戏状态机（GameStore）
├── scenes/
│   └── TownScene.ts         # Phaser 场景：世界渲染、相机、AI、战斗、战利品
└── ui/
    └── UIController.ts      # DOM 卡牌面板、商店、库存、操作菜单
```

- **顶栏** 显示：`Y年·M月·W周`、当前金币、本月税收、城镇等级、升级进度（当前/10）、场上牌数/上限、月份进度条。顶栏支持 `flex-wrap`，窄屏下 label 文字自动隐藏，只保留图标+数值。

- 窗口 resize 时 canvas 与所有 DOM 层同步调整，底部面板适配移动端 `safe-area-inset-bottom`。

## 时间系统

时间**完全自动推进**，玩家无法暂停或调速。

| 单位 | tick 数 | 实际时长（约） |
|---|---|---|
| 1 tick | 1 | 125 ms |
| 1 周 | 40 tick | 5 秒 |
| 1 月 | 160 tick（4 周）| 20 秒 |

每个 tick，`TownScene.update()` 通过累加器驱动：

```
tickAccum += delta
while tickAccum >= 125ms:
    doTick()
```

每 tick 依次执行：
1. 运行实体 AI（战士状态机、怪物行进、非战斗人员漫步）
2. 实时制造结算（累加勤劳点，满足条件立即产出）
3. 推进 `store.advanceTick()`（月末结算）
4. 若有新日志则推送到侧边栏并刷新精灵
5. 每 24 tick 尝试生成路过行人

## 卡牌系统

### 获取卡牌

商店一次展示 **6 张**卡牌（从当前城镇等级可用卡池中随机抽取，不重复直到池耗尽）。

- 购买后该格变为「已售出」占位，**同一格不可重复购买**。
- 6 张全部售出后**自动刷新**商店。
- 手动刷新商店花费 **5 金币**。
- 商店卡池受城镇等级限制：等级 N 的城镇只能出现 ≤ N 级的卡牌。

### 定价规则

同等级所有卡牌**价格相同**，功能差异不体现在价格上：

| 卡牌等级 | 购买价 | 场上维护费/月 | 手牌维护费/月（×0.5）|
|---|---|---|---|
| 0 | 20 | 5 | 3（向上取整）|
| 1 | 50 | 10 | 5 |
| 2 | 100 | 20 | 10 |
| 3 | 180 | 35 | 18（向上取整）|

> **怪物卡例外**：购买价与等级相同，维护费永远为 0。

### 打出卡牌

从手牌打出到场上，需满足场上牌数 < 当前上限。

- **人物卡**：打出时弹出岗位选择窗口（商店 / 制造 / 战斗）。
- **怪物卡**：打出时弹出出生点选择（左侧 / 右侧 / 顶部）。
- **建筑卡、魔法卡**：直接上场，无额外选项。
- 场上的牌**不能收回到手牌**，但可参与升级。

### 升级

集齐**任意来源（手牌 + 场上）共 3 张相同 id 的卡牌**可触发升级：

- 保留第一张，销毁另外两张。
- 升级后：`level +1`，`upgrades +1`，所有数值属性 **× 1.3**（取整）。
- 同时从当前卡池随机**免费获得 1 张**卡牌加入手牌。
- 升级后仍保留在原来的位置（场上或手牌）。

所有精灵统一使用 `origin(0.5, 1)`（底部居中），让脚部精确贴合地面线，避免浮空。

| 角色类型 | 纹理尺寸 | 渲染 scale | 实际显示高度（约）|
|---|---|---|---|
| 建筑 | 48 × 48 px | 1.0 | 48 px |
| 人物 | 48 × 48 px | 0.55 | 26 px |
| 怪物 | 48–60 × 48–54 px | 0.65 | 31–35 px |
| 行人 | 18 × 24 px | 1.0 | 24 px |

人物明显小于建筑，符合像素风比例习惯。

### 城墙外观

城墙包含：左右两翼延伸段、城门楼（带雉堞）、城门拱洞（带闸门）。城门楼高于城墙，设有箭孔。城外地面为夯土小路，城内为铺路石。

## 战士状态机

战斗岗位人物拥有独立的五状态 AI，优先级从高到低：

```
1. loot    → 正在前往战利品掉落点捡取
2. return  → 捡取完毕，返回兵营
3. fight   → 距离怪物 < 36px，进入攻击循环
4. chase   → 发现怪物，追击最近的一只
5. patrol  → 无怪物无战利品，在城门内来回巡逻
```

**战利品拾取流程**：
1. 怪物 HP ≤ 0 时，在怪物当前位置生成「战利品包」（emoji 图标）。
2. 最近的空闲战士感知到未被认领的战利品包，切换到 `loot` 状态，走向它。
3. 到达（距离 < 24px）后拾取，战利品加入库存，战利品包消失。
4. 战士切换到 `return` 状态，走回兵营，到达后切换回 `patrol`。
5. 多个战士分别认领不同的战利品包，不会重复认领。

## 战斗系统

### 侵略倒计时

怪物上场后初始化 `aggressionCountdown = aggression`（月数）。每月末减 1，归零时开始向城镇大厅进军。

> 注意：战士在怪物进入场上后**立即**开始追击，不需要等待倒计时归零。

### 实时战斗（tick 级别）

战士追至距离 < 36px 时进入攻击循环：

- `attackCooldown` 每 tick 减 1，归零时触发互相攻击，重置为 **2**（每 2 tick 打一次）。
- 命中时触发火花粒子特效。

伤害计算：

```
dmgToMonster = max(1, (human.atk + buff_human_atk) - monster.def)
dmgToHuman   = max(0, (monster.atk - debuff_monster_atk) - (human.def + buff_human_def))
```

### 战斗结果

**怪物 HP ≤ 0**：HP 重置，`aggressionCountdown` 重置，在怪物位置生成战利品包，怪物精灵飞回出生点。

**人物 HP ≤ 0**：HP 重置，`isActive = false`，`restMonthsLeft = townLevel`，精灵飞回城镇大厅，半透明显示。

### 行人与战斗的关系

当有任意怪物处于进攻状态时，当月行人数归 **0**，商店本月无收入。

## 经济链

```
战士击败怪物
       ↓
战利品包掉落在战场
       ↓
战士走去捡取 → 带回城镇 → 加入库存（战利品）
       ↓
制造人员每 tick 积累勤劳点 → 满足配方条件时自动合成 → 成品加入库存
       ↓
月末：商店人员 × 行人数 → 售出成品 → 获得金币
```

### 实时制造

每 tick，活跃的制造岗位人物以 `diligence / TICKS_PER_WEEK` 的速率积累勤劳点（`craftPoints`）。满足配方所需工时后立即产出，无需等待周末。月末**不重置** craftPoints（跨月积累）。

### 配方

| 输入战利品 | 数量 | 输出成品 | 工时 |
|---|---|---|---|
| 鼠皮 | 3 | 皮革 | 8 |
| 狼牙 | 2 | 武器 | 12 |
| 魔晶 | 1 | 魔法石 | 10 |
| 妖羽 | 4 | 羽毛斗篷 | 14 |
| 龙鳞 | 2 | 龙甲 | 20 |

### 月末商店结算

```
passersby = 5 + townLevel × 3 + getMagicBonus('extra_passersby')
sellCapacity = min(totalProducts, passersby × 2)
shopPower = sum(shopWorker.intellect)
income per item = product.sellPrice × (1 + shopPower × 0.05)
```

怪物进攻期间行人归 0，商店无收入。

## 月末结算流程

每月 160 tick 结束时，按以下顺序执行（执行完毕后自动存档）：

1. **税收**：`gold += monthlyTax(townLevel)`
2. **怪物侵略倒计时**：每只活跃怪物 `aggressionCountdown -= 1`
3. **商店收入**（详见上节）
4. **维护费**：场上非怪物牌全额扣除，手牌 ×0.5 上取整；金币不足时从场上倒序标记罢工
5. **恢复**：休息 / 罢工计时器各减 1，同时归零时恢复活跃
6. **城镇升级检查**：符合条件时升级

## 城镇升级

升级条件：`count(cards where card.level >= townLevel) >= 10`（手牌 + 场上合计）

升级效果：
- `townLevel += 1`
- 场上牌槽上限：`5 + (townLevel - 1) × 2`
- 商店自动刷新

城镇等级同时决定：每月税收金额、战败人物的休息时长、商店可出现的卡牌等级上限。

## 存档系统

- 存档时机：每月末结算完成后自动写入 `localStorage`，key 为 `town_legend_save`。
- 存档内容：金币、城镇等级、tick / week / month、手牌、场上、废弃牌、商店格子状态、库存、最近 50 条日志。
- 读档时机：页面加载时自动恢复，版本号不匹配时忽略旧存档。
- 版本号：`2`。

## 后续开发计划

以下功能按优先级排列，结合放置游戏的核心体验（"挂机观看人物自行活动"）进行规划。

---

### 高优先级

#### 制造与商店的视觉反馈
放置游戏的核心满足感来自"看到系统自动运转"，目前制造和交易完全没有视觉反馈，玩家感知不到人物在干什么。

- 铁匠制造时头顶显示像素进度条（用 Phaser Graphics 绘制，随 craftPoints 更新）
- 制造完成时头顶弹出产品 emoji，持续约 1 秒后消失
- 行人经过商店区域时，最近的商店人员走向行人短暂停留，模拟交易
- 交易完成时行人头顶弹出金币 emoji

#### 怪物击败冷却状态
- 怪物被击败后进入「受伤」状态（半透明红色叠加），持续约 3 个月月末倒计时后才恢复
- 当前版本被击败后立即重置 aggressionCountdown，节奏感较差，玩家看不出"有没有打赢"

#### 商店收入实时化
- 当前商店收入仍为月末批量结算，与"行人走过商店"的视觉演出脱节
- 计划改为：行人每次经过商店区，如库存有货则触发即时交易，金币当场结算
- 行人数量和购买力仍受当前公式约束，只是结算时机从月末改为实时

### 中优先级

#### 建筑卡接入结算
- 当前 `bonus` 与 `capacity` 字段已定义但未接入公式
- 计划：旅馆 → 每月行人数 +N；工坊 → 制造效率 +N%；兵营 → 战士攻防加成
- 建筑卡需要在对应区域内才生效（位置绑定）

#### 战士巡逻动画优化
- 当前巡逻为线性来回，缺少生命感
- 加入短暂驻足（随机停 1~2 秒）、左右环顾（翻转 sprite）动作
- 多名战士错开巡逻相位，避免同步行走

#### 战斗视觉强化
- 命中时被攻击方 sprite 短暂闪红（tween alpha 或 tint 效果），增强打击感
- 加大粒子数量和扩散半径，当前 5 个 4×4 方块视觉冲击偏弱
- 怪物被击败时播放短暂的震动/弹跳动画后飞回出生点

#### 城墙升级视觉
- 城镇等级 1–2：当前石墙风格
- 城镇等级 3+：更高、更厚的城墙，增加塔楼纹理
- 城镇等级 5+：城墙延伸段加长，覆盖更多区域

#### 事件日志过滤
- 当前日志混合战斗、经济、系统信息，信息密度高时难以阅读
- 添加分类筛选按钮：「全部 / 战斗 / 经济 / 系统」

### 低优先级

#### 月度总结弹窗
- 每月末弹出简短月报：本月收入 X、击败怪物 Y 只、制造商品 Z 件
- 可关闭，不阻断游戏时间（时间继续推进）

#### 数值平衡调整
- 当前前期维护费压力偏重：初始 120 金币，守卫 20 买入 + 5/月；商人/铁匠 50 买入，可能导致负循环
- 建议方向：降低 Lv0 卡牌手牌维护费，或提高 Lv1 初始税收补贴
- 需要真实游玩测试后再调整具体数值

#### 更多卡牌与配方
- 等级 3 人物卡（英雄、贤者、龙骑士等）
- 等级 3 怪物卡（亡灵、元素精灵等）
- 多输入配方（如「龙鳞 × 2 + 魔晶 × 1 → 龙魔甲」）

#### 城外地图扩展
- 城外左右各增加可探索的功能区域：矿山（自动产出矿石战利品）、森林（木材）
- 需要派遣专属「探索岗位」人物，探索人物出城后在城外区域活动，定期带回资源
- 与怪物出生点错开，互不干扰

#### 技能系统
- 人物升级后解锁被动技能（如铁匠「精锻」：制造时有概率双倍产出）
- 技能在卡牌详情面板展示
